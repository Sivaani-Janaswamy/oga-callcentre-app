# On-Ground.ai Call Centre App

A React, Vite, TypeScript, and Tailwind foundation for the On-Ground.ai call-centre staff app assignment.

## Run locally

```bash
npm install
npm run dev
```

Available checks:

```bash
npm run lint
npm run build
npm test
```

The current implementation contains the Phase 1 application shell and data services plus the
Phase 2 dashboard at `/dashboard`. The remaining routes still use the shared route placeholder
until their feature phases are implemented.
